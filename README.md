## 🚀 Aktuelle Projekte

### Carpe Deal – Tagesaktuelle Gastro-Deals in Berlin  

Carpe Deal bringt tagesaktuelle Angebote von Berliner Restaurants auf eine Plattform. Restaurants können ihre Deals selbst veröffentlichen, Nutzer entdecken passende Angebote in ihrer Umgebung auf einer interaktiven Karte.

Frontend
- Next.js mit App Router, React und TypeScript
- Responsive Design mit Tailwind CSS
- Desktop-Grid und Mobile-Carousel mit Touch-Swipe
- Lazy Loading und weitere Performance-Optimierungen

Backend
- REST API über Next.js Route Handler
- Token-basierte Authentifizierung mit Supabase
- Serverseitige Input-Validierung
- Business-Logik für die Veröffentlichung täglicher Deals
- Strukturiertes Error Handling mit passenden HTTP-Status-Codes
- Asynchrone Benachrichtigungen über die Telegram Bot API mit Retry-Logik

Datenbank
- PostgreSQL über Supabase mit Row Level Security
- Zeitzonenabhängige Abfragen für Berlin
- Indizes für häufig verwendete Abfragen

Integrationen
- Telegram Bot API für Benachrichtigungen
- Resend für E-Mail-Versand
- MapTiler für die interaktive Kartendarstellung

**Tech:** Next.js · React · TypeScript · Tailwind CSS · Supabase · PostgreSQL · Node.js

🌍 [Live ansehen](https://www.carpedeal.de)

### ZusammenWachsen App

Familienratgeber-App mit über 300 Themen, komplett offline nutzbar und auf Spendenbasis durch In-App-Purchases.
Die App ist öffentlich in den App Stores verfügbar und wird aktiv genutzt.

- **Solo-Projekt:** End-to-End-Umsetzung von Konzept, UX und technischer Umsetzung
- **Offline-Suche:** Fuzzy-Suche mit Fuse.js über 300+ Themen
- **Navigation & State:** React Navigation, Context API
- **Analytics & Fehlertracking:** datenschutzfreundliche Analytics (Supabase), Sentry
- **Release:** iOS & Android

**Tech:** React Native · Expo · JavaScript · Supabase · Sentry · Fuse.js
